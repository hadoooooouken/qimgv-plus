# Project Support & Issue Guidelines

⚠️ **Important Notice:** The Issues section of this repository is reserved **strictly for bug reports**. 

To keep development focused and organized, I kindly ask you to follow these guidelines:

### 🐛 Reporting Bugs
If you have encountered a bug, unexpected behavior, or a crash, please feel free to open a new Issue. 
* *Please provide as much detail as possible (steps to reproduce, OS version, logs, etc.).*

### 💬 Questions, Feature Requests & Discussions
If you want to:
* Ask a question about how to use `qimgv-plus`
* Suggest a new feature or improvement
* Discuss the project in general

Please **do not** open an Issue. Instead, use one of the following channels:
* [GitHub Discussions](https://github.com/hadoooooouken/qimgv-plus/discussions) *(Recommended)*
* My community chat (e.g., Discord/Telegram link if you have one)

---

> **Note:** Any Issues that are not actual bug reports (e.g., questions or feature requests) will be closed without review. Thank you for understanding and helping me keep the project clean!
